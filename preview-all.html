📦 How to Convert to GIF

Method 1: Using Online Tools (Easiest) ⭐ Recommended

  1. Go to ezgif.com/svg-to-gif
  2. Upload your chosen SVG file (e.g., logo.svg)
  3. Set dimensions to 200x200 pixels
  4. Set animation duration to 3-4 seconds
  5. Click "Convert to GIF"
  6. Download and optimize if needed to stay under 200KB

Method 2: Using FFmpeg (Advanced)

If you have FFmpeg installed, you can use this command:

# Install FFmpeg first if needed
# Then open the HTML file in browser and record
ffmpeg -i recording.mp4 -vf "fps=10,scale=200:-1:flags=lanczos" -loop 0 logo.gif

Method 3: Screen Recording

  1. Open the animated HTML file in your browser
  2. Use a screen recorder (QuickTime on Mac, OBS on Windows/Linux)
  3. Record 3-4 seconds of the animation
  4. Convert the video to GIF using ezgif.com/video-to-gif
  5. Crop to square and resize to 200x200px

💡 Tips for Email Profile Pictures

  • Size: Keep under 200KB for email compatibility
  • Dimensions: 200x200px or 150x150px works best
  • Duration: 2-4 seconds is optimal (not too long, not too short)
  • Loop: Make sure the GIF loops seamlessly
  • Test: Send yourself a test email to see how it looks!
